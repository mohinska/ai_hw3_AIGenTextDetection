# AI-Generated Text Detection

Solution to Homework 3 of the "Artificial Intelligence" course at UCU: classify a text as written by a human, generated by an LLM (`ai`), or a human text partially rewritten by an LLM (`fusion`).

## Task

- **Data:** English and German texts from news, scientific papers, blogs, parliamentary debates, court cases, student essays and books.
- **Classes:** `human`, `ai`, `fusion`.
- **Metric:** macro-F1 over the three classes (public LB: 30% of test, private: 70%).
- **Rules:** train on `train.csv` only, no external data, no proprietary LLMs; open-weight models are allowed.

## Validation

- One **fixed stratified validation split**: 10% of `train.csv`, stratified by label and language, seed 42 (`common.split_train_val`). Every model is compared on the same rows by **macro-F1**.
- Vectorizers, tokenizer-dependent preprocessing and any fitted transforms are fitted on the train part only.
- Each notebook saves validation and test class probabilities to `outputs/` so models can be ensembled later.
